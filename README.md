# CVForge — Live Markdown-to-ATS Resume Builder

A split-pane Markdown resume editor that renders clean, ATS-friendly layouts in real time with 3 switchable themes (`Executive`, `Minimal`, `Modern`), auto-save, and one-click PDF export.

## Quick Start
Open `index.html` in any browser, edit the Markdown on the left, and click **Export PDF**.
